> **极简 · 零依赖 · 跨机便携 · 工业级组件化**

## 🚀 一键极速启动

| 启动方式 | 操作说明 | 适用场景 |
| :--- | :--- | :--- |
| **🥇 首选启动** | **直接双击根目录下的 `start.bat`** | Windows 11 / Windows 10 桌面环境，秒级拉起服务并自动打开浏览器 |
| **🥈 终端启动** | 命令行执行 `npm start` | 开发调试或无桌面交互环境 |

启动成功后，浏览器将自动访问：`http://localhost:8901`（若端口被占用，服务会自动感知并分配备用端口）。

## ✨ 核心特性

### 1. 跨机 100% 便携与零外部依赖
- **纯原生技术栈**：基于 Node.js 18+ 内置原生模块（`node:http`、`node:fs`、`node:path`、`node:os`），**无需执行 `npm install` 下载任何 `node_modules`**。
- **动态路径自愈**：自动读取运行机器的 `%USERPROFILE%`，不硬编码任何机器用户名或绝对路径；拷贝至任何一台 Windows 11/10 电脑皆可直接双击运行。

### 2. 3D 语义认知引力场拓扑 (Galaxy View)
- **多层级天体系统**：
  - 🌟 **全局意图枢纽 (Core Anchor)**：中心恒星，代表项目顶层目标；
  - 📂 **主题认知域 (Topic Domain)**：环绕大行星，对应避坑经验、代码规约、技术栈等一级分类；
  - 💡 **记忆知识节点 (Memory Unit)**：卫星切片，展示具体的事实规约与解决方案；
  - 🔗 **链式激活流 (Activation Flow)**：带粒子光效的有向脉冲，呈现记忆间的衍生依赖；
- **全星体交互支持**：
  - 点击卫星、大行星、核心恒星，均可唤出详细基本信息面板；
  - 屏幕级悬浮发光基本信息卡片（HUD Tooltip）；
  - 自由拖拽重塑引力轨道。

### 3. 双模工作台与安全保护
- **只读保护模式 (🔒)**：默认开启，防止日常浏览与搜索时不慎修改核心规约；
- **编辑修改模式 (✏️)**：支持在抽屉面板中对标题、文件名、分类、适用场景、关键词、显式链式依赖及 Markdown 正文进行全字段编辑，`Ctrl + S` 一键原子化落盘并同步重构 `MEMORY.md` 索引。

### 4. 多项目智能动态识别与物理直读直写 (彻底告别软链接)
- **零软链接依赖**：自动动态扫描本地 Qoder CN 官方全局记忆目录（`~/.qoder-cn/memory`）与所有工程级记忆（`~/.qoder-cn/projects/*/memory`），支持国际版及本地备用库；
- **智能 Slug 源码反解**：通过贪心路径匹配算法自动还原工程真实磁盘源码路径，动态提取工程名与开发栈标识，无需手动打软链接；
- **Scope 作用域分组感知**：下拉菜单以 `<optgroup>` 明确区分 `🌐 全局记忆库 (Global Scope)` 与 `📁 本地工程记忆库 (Project Scope)`，支持一键 🔄 重新探测与 📂 在系统资源管理器中定位打开；
- **物理原子落盘与索引同步**：直接向本地真实物理路径落盘保存与删除切片，并自动同步维护 `MEMORY.md` 索引文件，立即对 Qoder IDE / CLI 生效。

## 🛠️ 常用运维指令

| 操作 | 指令 |
| :--- | :--- |
| **标准启动** | 双击 `start.bat` 或运行 `npm start` |
| **热重载开发** | 命令行运行 `npm run dev`（修改后端时自动重启） |

| **快捷保存落盘** | 页面内按键盘快捷键 `Ctrl + S` |
| **关闭弹窗/抽屉** | 按键盘 `Esc` 键 |
